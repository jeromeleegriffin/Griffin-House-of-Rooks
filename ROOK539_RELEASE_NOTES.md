# Rook539 — Pixel Measurement Overlay

- Preserves the Rook538 recovered portrait coordinates and newer gameplay fixes.
- Adds a read-only PIXELS developer overlay.
- 10 px grid with stronger 50 px guides.
- Exact live pointer X/Y readout and element identifier.
- Crosshair follows the pointer.
- Overlay uses pointer-events:none and does not move, resize, save, or otherwise alter game objects.
- Intended workflow: measure on the real layout, then make exact source changes such as “move bid box left 13 px.”
