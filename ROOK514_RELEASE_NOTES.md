# Rook514 visual roll

This is a surgical cumulative overlay for the current live Rook513 build.

Included:
- New portrait room background composed specifically for the narrow spaces visible around the existing oval table.
- No table resizing or gameplay-area reduction.
- Stronger removal of the old maroon top/bottom seat boxes, including pseudo-element chrome.
- Larger circular portraits; side portraits move farther outward across the rail while gameplay stays protected.
- Exact supplied Jerome portrait added as a selectable modern human avatar.
- Legacy/default rookling human portrait visually migrates to the modern Anchor portrait instead of the cartoon fallback.
- Landscape receives its third-pass information-first treatment: premium felt, thin walnut/brass surround, physical score rail, recessed Last-3 trays, subtle trick lighting and a shallow hand rack.
- Card dimensions, trick-history function, rules, AI, scoring, dealing and game mechanics are intentionally unchanged.
- Existing Rook513 host/waiting-room behavior guard remains in place.

Install:
Replace rook512-room.js and add rook514.css, room-card-club-514.jpg and avatar-jerome.png at repository root.
The existing Rook513 files remain in place.
