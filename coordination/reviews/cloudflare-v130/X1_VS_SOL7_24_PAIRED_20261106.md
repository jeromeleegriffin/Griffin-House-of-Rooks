# Cloudflare v130 X1 versus Sol7 full-play paired experiment

Date 2026-11-06. Exact deployed Cloudflare Worker `griffin-house-of-rooks-online`, active version `4335d4fa-d2ef-4d1e-9bad-dda40e71ce1e`, extracted from Cloudflare `content/v2` and executed in isolated in-memory harness with deterministic PRNG. **Not** a hosted browser or physical phone acceptance test. No production modifications or career changes.

## Design
All four bot seats (ISA, Crow, Anchor, Jerome). Two complete runs per deal, identical shuffled cards, dealers, auction decisions, discard and trump decisions; switch only trick-play algorithm: original sampled X1 `C.choose`, versus the existing `C.solmove` Sol7 policy by setting `room.x1.sol7=true` at play phase. No artificial bidding restrictions. Note that Sol7 decisions record `reason='sol7-hand'` as fallbacks in the diagnostic counters; these are **deliberate test configuration**, not runtime failures.

### Batch 1 (deals 0-11; seed formula 0x371092 + i*17011)
- 12/12 completed in each arm, identical auctions 12/12.
- Original X1 sets: 2/12. Sol7 sets: 2/12.
- Points changed in 10/12 deals.
- ISA 115: X1 captured 110, set; Sol7 captured 135, made.
- Jerome 115: X1 made; Sol7 set.
- Neither strategy was universally superior in this sample.

### Batch 2 (deals 20-31; seed formula 0xb7190 + i*24137)
- 12/12 completed in each arm; identical auctions 12/12.
- X1 sets: 3/12; Sol7 sets: 0/12.
- Partnership captured points differed on 10/12 deals; X1 higher in 3, Sol7 higher in 7, ties in 2.
- Average (X1 - Sol7) captured points: -10 per deal.
- Crow bid 115: X1 captured 80 (set) versus Sol7 130 (made).
- Anchor bid 135: X1 captured 115 (set) versus Sol7 165 (made).
- Crow bid 120: X1 captured 100 (set) versus Sol7 130 (made).

### Combined 24 paired deals
- All 48 full runs finished, with 24/24 identical auctions.
- **X1 5 sets / 24; Sol7 2 sets / 24.**
- 20/24 deals had different captured point totals with strategy alone changed.
- This indicates trick-play decisions can materially explain sets independent of bidding strength.
- Does **not** establish that globally replacing X1 with Sol7 is better, especially with small sample and a single all-bot cast. A larger paired test and per-trick analysis are needed.

## Important model mismatch
- Normal-rule online X1 `choosePreviousOnlineBotAction` uses `ONLINE_X1.core.ceiling()` for basic auction and `decideJump()` uses internal sampled `contract()` outcomes.
- Human-partner-aware `decidePartner()` simulates `contract()` continuations using a simplified move policy, while actual play invokes `ONLINE_X1.core.choose` sampled move evaluation plus partner exceptions.
- This **difference between forecast continuation and actual play policy** is a strong hypothesis for inaccurate make estimates, not yet a proved root cause.
