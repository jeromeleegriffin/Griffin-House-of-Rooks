# Rook528 — SOL Visual Layout Studio

Developer-only visual workbench for the actual Griffin House table.

- Replaces the narrow Phase 2 seat editor with a general live element picker.
- PICK ELEMENT selects live table/UI elements.
- Drag or type exact X/Y values; arrow keys nudge 1px, Shift+arrow 10px.
- Type width, height, scale, font size and z-index.
- Adjustable grid/snap; aspect-lock control reserved in the workbench UI.
- Hide/lock selected elements without deleting production defaults.
- Undo/redo, copy/paste values, reset selected item, reset current orientation.
- Guides and element-box overlays for alignment/clearance work.
- Portrait and landscape overrides remain independent.
- Export Layout produces JSON for promoting approved developer overrides into production defaults.
- SOL changes live in local developer overrides; production defaults are not rewritten.
- Normal players do not see the Visual Studio controls.
- No intentional rules, deal, shuffle, scoring, or multiplayer protocol changes.
- Locked fighting-ravens cabin artwork remains separate and untouched.
