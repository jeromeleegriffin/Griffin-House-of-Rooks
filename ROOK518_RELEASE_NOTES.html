Rook518 — Griffin House Signature Trump Medallion

Dedicated trump-only visual run. No game rules, bidding rules, card sizes, table geometry, room art, scoring, or networking logic were intentionally changed.

Signature declaration

  • Replaces the permanent HTML-style TRUMP pill with a physical brass-and-enamel Griffin House table medallion.
  • Trump declaration now lands once as COLOR IS TRUMP, compresses on impact, clears, and resolves into the resting marker.
  • The permanent state is deliberately quiet: no idle bounce, pulse, spin, particles, or repeated announcement.

Card-accurate color identity

The medallion enamel is derived from the production card-face colors:

  • Green: #00b34a
  • Red: #ff1744
  • Yellow: #b8860b
  • Black: #111111

Yellow is shaded as enamel/brass rather than neon yellow. Black retains highlight and material depth rather than becoming a flat dark disk.

Trump-play reactions

  • Playing an ordinary trump causes a microscopic settle and enamel light response.
  • Playing the Rook produces a slightly stronger brass response.
  • Neither effect interrupts play or creates a second announcement.

Safety / accessibility

  • Portrait and landscape use the same object with landscape reduced to protect the large-card reading view.
  • Reduced-motion mode keeps the resting marker and removes the slam/reaction animation.
  • The marker remains announced to assistive technology as COLOR is trump.

Jerome portrait preservation

avatar-jerome.png is intentionally not included in this package because the local Rook517 package carried the rejected gold-ring copy while GitHub main correctly retained the frameless portrait. Extracting Rook518 over the repository therefore leaves the approved existing portrait untouched.
