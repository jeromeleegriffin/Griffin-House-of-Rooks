# Rook537 — SOL Quick Move

- Replaces the giant SOL panel as the default editing surface with a tiny movable Quick Move controller.
- PICK selects one live object.
- SELECT ALL selects the stable visible table UI group while deliberately excluding table/background/structural containers.
- Arrow pad moves the selected object or selected group in 10px steps without changing relationships inside the group.
- CLEAR drops the temporary group selection.
- UNDO reverses the last group move; single-item undo continues to use SOL history.
- ADVANCED opens the existing full SOL panel only when needed.
- DONE exits editing.
- Existing multiplayer re-entry and avatar ownership work from Rook536 is retained.
